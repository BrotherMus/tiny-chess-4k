A chess engine in under 4 KB of Python: alpha-beta with a transposition table, quiescence, null-move and late-move reductions on a flipped mailbox board, searching a fixed node budget so every game replays move for move.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
